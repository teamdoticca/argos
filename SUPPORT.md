# Support

Use [GitHub issues](https://github.com/teamdoticca/argos/issues) for reproducible bugs and scoped feature requests. Search existing issues first. Include the Argos version, OS and architecture, Node/.NET version, a synthetic repository layout, expected behavior and actual output.

For installation problems, consult [compatibility and troubleshooting](docs/COMPATIBILITY.md). For development and verification, read [CONTRIBUTING.md](CONTRIBUTING.md). Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Doticca maintains Argos on a best-effort basis. There is no guaranteed response time, commercial support commitment or stability guarantee for unreleased code. Avoid including private paths, tokens or customer content in reports.
